# Фурузон — личный кабинет преподавателя

Веб-сайт для преподавателей: загрузка списков групп из Excel, работа с таблицами студентов и раздача учебных материалов студентам по QR-коду.

Студенты на сайт не заходят: они только сканируют QR-код и получают файл. Каждый преподаватель видит только свои данные.

## Возможности

### Мои группы
- Загрузка списков студентов из `.xlsx` и `.xls` (до 10 МБ).
- Автоматический поиск строки заголовка в «грязной» шапке файла, с предпросмотром и ручным выбором.
- Колонки как в исходном файле: их можно переставлять и удалять.
- При сохранении указываются номер группы и курс (1–6); карточки групп сгруппированы по курсам.
- Редактирование ячеек кликом, поиск без учёта регистра и с допуском опечаток.
- Экспорт группы обратно в Excel.

### Раздаточные материалы (в разработке)
- Загрузка файлов PDF, DOC, DOCX (до 10 МБ) с привязкой к курсу и одной или нескольким группам.
- Дерево «Курс → Группа → файлы».
- Один QR-код на файл: публичная ссылка без срока действия, файл скачивается сразу.
- Хранение файлов в Supabase Storage.

### Общее
- Регистрация по email и паролю, сброс пароля письмом.
- Интерфейс на русском и таджикском языках.
- Светлая и тёмная темы.
- Адаптивная вёрстка: нижняя навигация на телефоне, боковое меню на ПК.
- Главная страница с последними действиями преподавателя.

## Технологии

- Python, FastAPI
- Шаблоны Jinja2, JavaScript и CSS без фреймворков (`app/static`)
- Миграции Alembic
- Supabase Storage для файлов
- Отправка писем через SMTP (настройки в `.env`)
- pytest для тестов

Подробности: `docs/STACK.md`, `docs/ARCHITECTURE.md`.

## Запуск локально

1. Клонировать репозиторий и перейти в папку проекта.
2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   ```
3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Создать файл `.env` на основе `.env.example` и заполнить параметры БД и секретный ключ. Локально загруженные файлы сохраняются в папку `UPLOADS_DIR` (`STORAGE_BACKEND=local`); для деплоя хранилище переключается на Supabase через переменные `STORAGE_BACKEND=supabase` и `SUPABASE_*` в `.env`.
5. Применить миграции:
   ```bash
   alembic upgrade head
   ```
6. Запустить сервер:
   ```bash
   uvicorn app.main:app --reload
   ```
7. Открыть http://127.0.0.1:8000
